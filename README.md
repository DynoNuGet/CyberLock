# CyberLock

> Projeto interdisciplinar desenvolvido para entrega na Etec de Taboão da Serra no ano de 2026

---

## Descrição do Projeto

Um site informativo gamificado com objetivo de conscientizar e instruir a população quanto ao tema de vazamento de dados e informações pessoais no ambiente virtual.

### Principais Funcionalidades
- **Imersão com jogos:** O site utiliza de jogos para facilitar o entendimento e memorização do conteúdo, além de propor desafios práticos e divertidos para os usuários.
- **Conteúdo confiável:** O site conta com conteúdos de fontes verificadas e confiáveis para a dispersão de suas informações.
- **Praticidade:** Por ser um site, pode ser acessado de qualquer dispositivo, seja ele mobile ou desktop, que possua acesso à internet.
